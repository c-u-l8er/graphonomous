# SOURCE QUALITY FINDINGS — what the registries look like from an ingestion adapter's seat

**Status:** observations made while reading the sources during G-PR0 (2026-09-02). None of these is a stack
(WRL/TRVM/WEK) gap; they classify as `NOT_A_STACK_PROBLEM` in the register and become G0 fault reports or G1
diagnostics. Nothing here was changed in the sources — other lanes own them.

| # | Source | Observation (measured) | G0 consequence |
|---|---|---|---|
| Q-01 | crosswalk `records[].derivation_links` | mixes record ids (`E-02`) with free prose (`"S3 enforcement property (a)"`, `"Kleppmann fencing token; ROTE … (prior art)"`) in one array; 30 records carry links, of which the execution-lane records (E-13a…E-51) are almost entirely prose | an adapter must classify each link: id-shaped → `DERIVES_FROM` edge; prose → an `UNRESOLVED_LINK` fault node attached to the record, never silently dropped and never turned into an edge by guessing |
| Q-02 | crosswalk `promotions[].to` | the field text is truncated with a literal `…` in the file (E-13b, E-14) | ingest as-is; flag `TRUNCATED_FIELD`; the full "to" state is the record's own `evidence_class` |
| Q-03 | crosswalk / evidence_state `executed` | only 8 of 56 records carry `executed`; `evidence_state.records[].executed` is `null` for 48 of 56 even where `evidence_class_token` is `TESTED` (e.g. E-01) | "TESTED with no executed receipt" is not decidable from these two files alone; the honest G0 answer is *unknown-from-data*, and the G1 diagnostic must say which rule made it so |
| Q-04 | crosswalk `witness_paths` | paths are relative to three different roots: the package (`witnesses/…`), the lane root (`experiments/…`, `px13/…`) and the computedriven repo (`tools/compile-fail/…`, `receipts/R0.7.md`, `cd-node/tests/…`); one entry carries a parenthetical (`"experiments/distributed_currentness/receipts/EXP1-ARM-A.json (the same shape across a namespace boundary)"`); fragment anchors appear (`#M2`, `#E-50a`, `#findings`) | the adapter resolves each path against an ordered root list recorded in the ingestion contract, records which root matched, and emits `DANGLING_WITNESS` when none does; parentheticals are stripped and kept as a note |
| Q-05 | crosswalk `scope_profile`, `trust_profile`, `conditions` | free text, no profile registry; the same profile appears in several spellings (`single log`, `single-log persistent agents`) | PROFILE nodes are minted per distinct normalized text and marked `unnormalized: true`; equivalence between spellings is a G1 *proposal*, never an adapter merge |
